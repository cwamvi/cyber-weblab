Gerador de Senhas

Senhas fracas são uma das portas de entrada mais usadas por criminosos. Gere uma senha forte e diferente para cada serviço.

Dicas para criar boas senhas

  • Use 12 caracteres ou mais.
  • Misture letras maiúsculas, minúsculas, números e símbolos.
  • Use uma senha diferente para cada serviço.
  • Evite datas de nascimento, nomes de familiares e sequências como "123456".
  • Nunca envie sua senha por mensagem, nem para quem diz ser do suporte.

Projeto acadêmico baseado na cartilha "Golpes: Evite Fraudes" do CERT.br/NIC.br.
